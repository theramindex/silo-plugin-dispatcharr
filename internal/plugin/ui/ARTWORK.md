# Sports fallback artwork

Sports cards use fixed decorative photographs selected by sport, with league
aliases used when the sport name is missing or ambiguous. These photographs do
not identify the current event's venue and are not live camera feeds.

Provider event artwork takes precedence. Otherwise, the card uses a sport photo,
then the GameThumbs background if the photo is unavailable, then the local
scoreboard layout. Team/league logos, event names, and scores remain separate
from the background. The same photo selection applies to matchup, program, and
race cards. Unrecognized sports retain their existing GameThumbs backgrounds.

Photos are fetched directly from the image CDN at 1200 px width, quality 80, with
automatic image format and lazy loading. Normal browser/CDN caching applies;
there is no periodic background-photo refresh or venue lookup.

All photographs below were verified as free under the
[Unsplash License](https://unsplash.com/license) on 8 September 2026 UTC.
Premium Unsplash+ photos are not used. Photos are cropped and shaded for text
legibility. These source records are documentation and are not rendered in the
user interface.
