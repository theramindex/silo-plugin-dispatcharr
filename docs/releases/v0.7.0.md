# Dispatcharr 0.7.0

- Share authenticated continuous MPEG-TS/HLS playback, viewer-owned sessions, and cleanup with XC and HDHomeRun.
- Share two GPU compatibility slots across Live TV plugins; support bounded GPU rewind history while retaining Direct-only rewind and DVR rules.
- Add explicit station priorities and startup alternatives, guarded pooled HTTP clients, and combined cache administration.
- Update to Silo Plugin SDK v0.30.0.

Validation: repository release checks, shared race and browser lifecycle tests, local emulator playback checks, and MPEG-2/AC-3 to H.264/AAC conversion on the Silo server GPU. Physical HDHomeRun hardware was not available; device tests use local emulators and Dispatcharr.
